Добавлены обновления приложения через GitHub Releases.

- Проверка новой версии при открытии приложения и раз в час.
- Отметка доступного обновления во вкладке «Ещё» и в настройках.
- Загрузка и установка APK по кнопке, с сохранением настроек и заметок.
- Проверка контрольной суммы, версии и подписи APK перед установкой.

Расписание и замены по-прежнему загружаются напрямую с сайта колледжа.
