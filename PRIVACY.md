# Политика конфиденциальности KASICT

Редакция от 1 ноября 2026 года.

## О приложении и разработчике

KASICT показывает расписание и замены колледжа. Разработчик приложения — rwarx. Эта политика описывает данные и сетевые обращения Android-приложения и веб-версии. Для использования не требуется учётная запись KASICT.

Приложение не запрашивает имя, телефон, электронную почту, контакты или геолокацию. Выбранная группа и личные заметки не отправляются разработчику, в счётчик посещений или в сервис обновлений.

## Что хранится на устройстве

На устройстве сохраняются выбранная группа, заметки к парам, параметры оформления и уведомлений, последнее расписание, история расписания, сведения о проверках и ошибках загрузки. Для счётчика сохраняется отметка учёта посещения за дату и последнее известное общее число посещений. Эти данные нужны для работы настроек, уведомлений и доступа без интернета.

История расписания очищается при сохранении новых снимков: удаляются записи старше семи дней и записи сверх лимита 200 снимков. Остальные настройки и заметки сохраняются до их изменения или удаления пользователем. Загруженные APK и изображения для отправки находятся во временном кеше.

KASICT самостоятельно не синхронизирует личные данные между устройствами. В Android разрешено системное резервное копирование: ОС может включать данные приложения в резервную копию или перенос на другое устройство в соответствии с настройками устройства и правилами поставщика резервного копирования.

## Загрузка расписания и уведомления

Android-приложение загружает общедоступные страницы расписания и замен с сайта kasict.ru. Выбор нужной группы выполняется на устройстве. Веб-версия получает подготовленные файлы расписания с сервера, на котором она размещена; при использовании официальной веб-версии это GitHub Pages.

Серверы сайта колледжа и веб-хостинга получают IP-адрес, время обращения, адрес запрошенного ресурса и технические сведения запроса. Они могут сохранять эти сведения в своих журналах. Группа и текст личных заметок не добавляются приложением к этим запросам.

Уведомления о заменах формируются на устройстве после проверки расписания. В Android обычная фоновая проверка и включаемый пользователем быстрый режим могут обращаться к сайту при закрытом приложении. Быстрый режим показывает постоянное уведомление. Отдельный сервер push-уведомлений KASICT не используется.

- [Сайт колледжа](https://kasict.ru/students/schedule/)

## Счётчик посещений Abacus

Для показателя «Пользователей сегодня» используется сторонний сервис Abacus по адресу abacus.jasoncameron.dev. При запуске приложение обращается к общему счётчику kasict.app за текущую дату, чтобы увеличить его на единицу. Повторный учёт ограничивается отметкой на устройстве: обычно одно устройство учитывается не более одного раза в сутки. После очистки данных или при недоступном локальном хранилище повторный учёт возможен, поэтому показатель приблизительный.

При открытии настроек приложение также запрашивает текущее общее значение счётчика. В адресах запросов передаются название общего счётчика и дата. Приложение не добавляет к ним выбранную группу, заметки, имя, рекламный идентификатор или уникальный идентификатор устройства.

Abacus и обслуживающая его инфраструктура получают IP-адрес, время обращения, адрес ресурса и технические сведения запроса, в том числе сведения браузера или WebView. Поэтому обращения к счётчику нельзя считать полностью анонимными для его владельца. Разработчик KASICT использует только общее число посещений, возвращаемое публичным счётчиком; индивидуальные записи посещений в приложении не создаются.

Разработчик KASICT не управляет журналами Abacus и не определяет сроки хранения его технических данных. Недоступность счётчика не мешает работе расписания.

- [Сервис Abacus](https://abacus.jasoncameron.dev)

## Обновления Android-приложения

Наличие новой версии проверяется при открытии приложения, возвращении из фона и раз в час на видимом экране. Автоматические запросы ограничены одним в час; ручная кнопка позволяет проверить раньше. Для проверки загружается небольшой файл с описанием релиза из публичного репозитория rwarx/kasict-android-releases на GitHub. Учётная запись и токен GitHub не требуются.

Установленная версия сравнивается с релизом на устройстве. Группа, заметки, настройки и номер установленной версии не добавляются к запросу проверки. GitHub и его инфраструктура доставки файлов получают IP-адрес, время обращения и технические сведения запроса. При загрузке APK адрес ресурса содержит версию скачиваемого релиза.

APK скачивается только после нажатия «Скачать и установить». Приложение проверяет размер, SHA-256, имя пакета, версию и совпадение сертификата подписи с установленным приложением. Установку подтверждает пользователь в системном окне Android. Разрешение устанавливать обновления из KASICT можно отозвать в настройках Android.

Дата проверки, описание найденного релиза и ошибки сохраняются локально. APK хранится в кеше для установки и повторной попытки; кеш может быть очищен пользователем или системой. Обработка технических данных GitHub описана в его политике конфиденциальности.

- [Репозиторий обновлений](https://github.com/rwarx/kasict-android-releases)
- [Политика конфиденциальности GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)

## Внешние ссылки и функция «Поделиться»

Telegram-канал, профиль разработчика и другие внешние страницы открываются по нажатию пользователя. После перехода обработка данных регулируется правилами выбранного сервиса. Приложение не входит в вашу учётную запись Telegram или GitHub.

При использовании «Поделиться» выбранный текст, ссылка или изображение передаются в приложение, которое вы выберете в системном меню. В веб-версии возможна запись в буфер обмена по нажатию пользователя. Перед отправкой проверьте содержимое: выбранная группа может быть видна в расписании, которым вы делитесь.

- [Политика конфиденциальности Telegram](https://telegram.org/privacy)

## Как управлять данными

Заметку можно удалить в её редакторе, историю расписания — через «Ещё → Сохранённые снимки → Очистить». Настройки группы и уведомлений можно изменить в приложении. Разрешения на уведомления и установку APK можно отозвать в настройках Android.

Чтобы удалить локальные данные Android-приложения, используйте «Настройки Android → Приложения → KASICT → Хранилище → Очистить данные». Очистка кеша удаляет временные файлы, но не заменяет очистку данных. В веб-версии удалите данные сайта в браузере. Резервные копии управляются отдельно в настройках устройства или сервиса резервного копирования.

Локальная очистка не удаляет уже учтённое посещение из общего счётчика и не удаляет журналы сторонних сервисов. Совокупное число посещений не содержит идентификатора, позволяющего выделить и удалить конкретное посещение через приложение. Сроки хранения и обращения по поводу серверных журналов определяются владельцами соответствующих сервисов.

## Изменения политики и связь

Актуальная редакция политики включена в приложение и опубликована в публичном репозитории релизов. Изменения обработки данных будут описываться в новой редакции политики и примечаниях к обновлению. Дата редакции указана в начале документа.

По вопросам конфиденциальности можно обратиться к разработчику rwarx через GitHub Issues репозитория релизов. Это публичный канал: не размещайте там личные заметки, пароли, токены или другие чувствительные сведения. При обращении GitHub обрабатывает данные вашей учётной записи и сообщения по своей политике.
