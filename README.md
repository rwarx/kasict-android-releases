# KASICT для Android

Установочные APK приложения KASICT. Исходный код хранится отдельно в приватном репозитории.

**[Скачать последнюю версию](https://github.com/rwarx/kasict-android-releases/releases/latest)**

Приложение получает расписание и замены напрямую с сайта колледжа. Чтобы установить обновление, открой «Ещё» → «Обновления приложения» → «Скачать и установить». Android попросит разрешить установку из приложения и подтвердить обновление. Настройки и заметки сохраняются.

В каждом релизе: `KASICT-Android.apk`, `update.json` и `SHA256.txt`.
